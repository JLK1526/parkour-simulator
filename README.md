# 跑酷模拟器

## 游戏简介

一款无需安装、双击即玩的单文件 HTML5 跑酷小游戏。角色自动从左向右持续奔跑，玩家只需控制**跳跃**与**下蹲**躲避不断出现的障碍，跑得越远得分越高。

游戏以蓝色为主视觉，支持浅色/深色主题、四类障碍、三档难度、皮肤装扮与技能商店、金币经济系统，以及带静音开关的完整音效。所有存档保存在浏览器本地（localStorage），刷新页面不丢失。

**玩法**

### 操作方式

| 操作 | 屏幕按钮   | 键盘               |
| -- | ------ | ---------------- |
| 跳跃 | `↑ 跳跃` | `↑` / `空格` / `W` |
| 下蹲 | `↓ 下蹲` | `↓` / `S`        |

- 购买「二段跳」技能后，在空中可再跳一次。
- 下蹲持续约 0.5 秒，松开后自动起身。

### 障碍类型

| 障碍   | 外观        | 通过方式       |
| ---- | --------- | ---------- |
| 路障   | 橙色矮块      | 跳跃         |
| 横杆   | 紫色固定横杆    | 下蹲         |
| 高墙   | 红色高墙，标「跳」 | 跳跃（起跳窗口更窄） |
| 升降横杆 | 上下浮动，标「↕」 | 下蹲         |

碰到障碍即游戏结束。购买「能量护盾」后每局可免疫一次碰撞。

### 热身区与金币

- 开局前 **420 米**为热身区：无障碍、不产金币，让你先熟悉节奏。
- 热身结束后，每跑 **20 米**获得 **1 枚金币**。
- 实际金币收益还会叠加难度倍率（困难 ×1.5）与「金币加成」技能（×2）。
- 金币在碰撞失败后结算入账，用于商店消费。

### 难度选择

首页可选择三档难度，影响初速、加速斜率、障碍间距与尺寸：

| 难度 | 特点      | 得分倍率 | 金币倍率 |
| -- | ------- | ---- | ---- |
| 简单 | 慢速、障碍稀疏 | ×0.8 | ×0.8 |
| 普通 | 标准节奏    | ×1   | ×1   |
| 困难 | 高速、障碍密集 | ×1.6 | ×1.5 |

### 商店

首页左上角（或结算页）进入商店，用金币购买：

- **角色皮肤**（6 款）：经典蓝、烈焰红、森林绿、星云紫、黄金战甲、幻影白。购买后立即装备，角色与首页立绘同步变色。
- **个性装扮**（6 款）：无、疾风围巾、酷炫墨镜、棒球帽、光翼、王者皇冠，直接绘制在 Canvas 角色上。
- **技能**（3 种）：二段跳（空中再跳一次）、能量护盾（每局免疫一次碰撞）、金币加成（收益 ×2）。技能可在商店中随时开关。

### 其他功能

- **主题切换**：页面右上角一键切换浅色/深色，偏好本地保存。
- **音效开关**：右上角 `🔊`/`🔇` 控制。跳跃音与死亡音为内嵌音频，其余为实时合成音效；静音状态本地保存。
- **本地存档**：金币、已购物品、当前装备、难度、最佳分、主题、静音状态全部保存在浏览器 localStorage。
- **结算反馈**：碰撞失败后显示本次得分、最佳分与金币收益，可重新开始或返回首页。
